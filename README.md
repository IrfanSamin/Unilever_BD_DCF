# DCF Valuation — Unilever Bangladesh

A discounted cash flow model built to estimate the intrinsic value of Unilever Bangladesh, a company listed on the Dhaka Stock Exchange (DSE).

## What's inside

- Historical financial statement review and revenue projections
- WACC estimation using cost of equity and cost of debt
- Terminal value calculation (Gordon growth method)
- Sensitivity analysis on discount rate and growth assumptions

Built independently as a self-study project applying corporate finance concepts to a real, listed company. Feedback and suggestions are welcome.
